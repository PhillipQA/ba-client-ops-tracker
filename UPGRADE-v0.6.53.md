# BA Client Ops Tracker v0.6.53

## FSD image supporting documents

- FSD Creation now accepts PNG, JPG/JPEG, WEBP, BMP, TIF and TIFF images up to 10 MB each.
- Images are read with English OCR in the browser and automatically added to the FSD source list as **Supporting document** sources.
- Existing PDF, DOCX, TXT, MD, CSV and JSON source support is unchanged.
- Visual-only diagrams are not interpreted; review the extracted OCR text before generating the FSD.

No database migration or dependency installation is required.
