# v0.6.84 — FSD and BRD generation survive unreadable AI replies

This release fixes the "The AI returned an invalid document" failure in the FSD creator. See the [changelog](../../CHANGELOG.md) for details.

- **Repair.** A reply with a line break or an unescaped quotation mark inside the text, a trailing comma, or extra words or code fences around the document is now read correctly instead of rejected.
- **One automatic retry.** If a reply still cannot be read, the FSD and BRD previews ask the AI once more before reporting an error.
- **Clearer errors.** The message no longer tells you to reduce the scope when the cause is an unreadable reply. Your draft and sources are kept.

No database migration is needed.

After the deploy, open the public app URL and confirm the current version, **v0.6.84**.
