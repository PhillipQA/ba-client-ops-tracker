# v0.6.46 — Communications Hub layouts and readable themes

## Changes

- Switch between Cards and Rows across All, Gmail, Discord, Manual, and Archived. Each layout opens the same private message and task creation view.
- Choose 5, 10, or 15 messages per page (default: 10). Previous/Next controls include page numbers and a matching result count.
- Layout and page size are remembered per tenant and user in the current browser.
- Source, Gmail label, and page-size changes return to page 1. Archiving the last message on a page moves back to the last available page.
- Pagination runs in the database after tenant, user, source, archive, and label filtering, so imported history beyond the former 200-message window is accessible. This does not import additional Gmail messages; Gmail sync still imports up to the latest 30 per selected label.
- Message cards, rows, controls, detail panels, and integration settings use matching background/text colors. They follow My Themes interface mode (Dark, Light, Gray); when using the background theme's original appearance, they inherit its palette. No changes to document templates or background images.
- Long subjects and sender addresses wrap or truncate inside their own cards. Row layout adapts to narrow screens.
- Opening a message loads the owner's imported thread separately from the list page. Threads load 50 messages at a time, with a Load more control for longer imported conversations.

## Upgrade from v0.6.45

No new SQL migration, environment variable, dependency, or OAuth reconfiguration is required. Existing schema v12 and v13 from v0.6.44/v0.6.45 remain prerequisites.

Back up the app, stop the local server, then run from your project folder (adjust the archive path if needed):

```powershell
npm run patch -- "E:\Playwright\ba-client-ops-patch-v0.6.46-communications-layout.zip"
npm run build
npm run patch:status
```

Restart the app or deploy the updated source to Render, then refresh the browser. Deploy both frontend and server changes together; the new list requests use the paginated API. The full build is also supplied for a fresh source checkout. Keep your existing environment configuration.
