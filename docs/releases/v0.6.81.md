# v0.6.81 — Create multiple tasks from one Gmail message

Previously, creating a task closed its Work Hub panel and a saved task link blocked later task creation from the same email. Work Hub now supports multiple distinct tasks from one communication without restarting or signing out.

- Duplicate top-level Task titles are rejected for the same client and project. Comparison ignores case, surrounding spaces and repeated whitespace. The check covers all existing tasks regardless of the source email or assignee; subtasks and other item types are separate.
- Duplicate attempts show a popup and keep the draft intact. The server rechecks the current workspace and serializes communication task submissions per workspace.
- After a successful creation, the email and task form remain open. Client, project and assignee stay selected; title and shared description reset for the next task. An explicit Close button dismisses the panel.
- A workspace-refresh or private message-badge failure reports that the task was saved, so the user does not retry an already-completed creation.
- The existing shared communications route also supports multiple distinct tasks for Discord and manual logs. Source messages remain private; tasks contain only the submitted shared fields.

No database migration is needed. Existing communication badges are retained and identify the latest created task.

Validation includes server and React DOM regressions for repeated creation, duplicate warnings, concurrent requests, double-clicks, field preservation and refresh failures; production build and server typecheck.
