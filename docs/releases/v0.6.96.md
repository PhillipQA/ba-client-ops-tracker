# v0.6.96 — Trackers: move rows, change column type, task links

There is **no new Google permission**. There is **one optional database migration**: apply [`database/migrations/schema-v25-tracker-task-links.sql`](../../database/migrations/schema-v25-tracker-task-links.sql) once (Supabase or Northflank PostgreSQL) to use task links. Without it, everything else works, and the link card says the migration is missing.

- **Move rows:** select rows, then **Top**, **Move up**, **Move down**, **Bottom**, or drag by the row number. Only while no sort, grouping, search or filter is active.
- **Change a column's type** (Text, Long text, Number, Date, Link, Select): **Check the change** shows what would be cleared; nothing is cleared until you confirm.
- **Tasks and subtasks on a row or cell:** link as many as you like in the row panel. The Action Center shows each one on its follow-up date with the tracker, row and cell it came from; click to open the row.
- **Readable footer** on a solid rounded background, and a **compact Full view** with icon-only Import, Export and Exit full view.

After the deploy, confirm **v0.6.96**, hard refresh (Ctrl+Shift+R), apply schema v25, then link a subtask to a tracker row, set its follow-up date to today and look for it in the Action Center.
