# v0.7.0 — Type-to-search clients and open-only task pickers

There is **no database migration and no new Google permission**.

- **Client fields you type into**, everywhere a client is chosen (tasks, reports, requirements, documents, DocHub, email, Work Hub, Git tickets, trackers): type part of the name and pick it; the list is A to Z.
- **Task and subtask lists show only open work** in New email, Document Creation (Save to Drive), DocHub, Git ticket linking and Work Hub's Save to Drive. Closed and resolved follow your task statuses in Settings.

After the deploy, confirm **v0.7.0**, hard refresh (Ctrl+Shift+R), open New email → Linked task or subtask, type a few letters of a client, and check a resolved subtask is not offered.
