# v0.6.89 — Google Drive in Document Creation

Google Drive now works inside Document Creation. No database change; Google Drive must already be connected (v0.6.87).

- **Signed DRF and Sign Off PDFs file themselves.** When DocHub shows the document as fully signed, the signed PDF is saved under `BA Client Ops Tracker / Client / Project / Task / Subtask`, using the task or subtask linked in DocHub options. With no task linked, it goes to `Client / Project`. The task lists it under **Saved to Google Drive**.
- **A Drive problem never affects the signature.** Failed saves are retried a few times, and the document card has a **Save to Google Drive** button. The same button files documents signed before this release.
- **Choose from Google Drive in DRF Creation** lists the files the tracker saved to tasks and subtasks, such as a COR saved from an email.
- **Generated BRD, FSD and test case documents** can be saved to a task or subtask with **Save to Google Drive**.

After the deploy, open the public app URL and confirm **v0.6.89**, then hard refresh (Ctrl+Shift+R). To check it, link a task or subtask when preparing a DRF in DocHub, sign it, and look for the PDF in that task's Drive folder.
