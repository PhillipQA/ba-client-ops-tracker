# BA Client Ops Tracker v0.6.59 — PDF report source reading

FSD source ingestion now captures embedded PDF screenshots individually during rendering and OCRs them at a readable resolution. The original selectable text remains separate evidence. Repeated screenshots are identified instead of repeating their text. If the image objects cannot be captured, the existing full-page OCR remains a fallback.

For report templates, source review is instructed to extract legible titles, fields, categories and notes while treating example dashboard figures as samples. Missing formulas, date filters, data sources and transaction rules become clarification gaps. OCR output still needs comparison with the original PDF, especially numbers and visual relationships.

This changes no database schema or dependencies. See [UPGRADE-v0.6.59.md](../../UPGRADE-v0.6.59.md) and [verification-v0.6.59.md](verification-v0.6.59.md).
