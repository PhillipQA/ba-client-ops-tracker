# v0.6.85 — Readable BRD and FSD previews

This release fixes pale, hard-to-read text on the BRD preview page. See the [changelog](../../CHANGELOG.md) for details.

- **BRD preview.** Headings, table cells, lists, the summary and the edit controls are dark on the white page in the dark appearance and with wallpaper themes.
- **FSD preview.** The same protection applies, including table headers in the older appearance with a wallpaper theme and the notes inside the "Partial draft" warning.
- **Word exports** are unchanged.

No database migration is needed.

After the deploy, open the public app URL and confirm the current version, **v0.6.85**. A browser with the old version open may need one hard refresh (Ctrl+Shift+R).
