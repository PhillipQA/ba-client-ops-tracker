# v0.6.88 — Save to Drive works on every message in an email thread

A thread in Work Hub shows every message in it, and each message has its own attachments. Until now a task was linked only to the message that was open when it was created, so an attachment on an older message in the same thread said "Create a task from this email first" even though the task existed.

**Save to Drive** now offers the tasks, and their subtasks, created from any message in the thread. Nothing else changes: only the owner of the email can save its attachments, a different thread cannot file into those tasks, and archived work is not offered. The task list also reloads each time the picker opens.

There is no database change. Redeploy, then open the public app URL and confirm **v0.6.88**. A browser with the old version open may need one hard refresh (Ctrl+Shift+R).

If the picker is still empty, the task was probably created on the **Tasks** page rather than from the email. Tasks are linked to an email only when you use **Create a project task** in Work Hub.
