# v0.6.99 — Only open tasks in task pickers

There is **no database migration and no new Google permission**.

The task and subtask lists in New email, Document Creation (Save to Drive), DocHub, Git ticket linking and Work Hub's Save to Drive now show only open work. Closed and resolved items follow your task statuses in Settings.

After the deploy, confirm **v0.6.99**, hard refresh (Ctrl+Shift+R), resolve a test subtask and check it no longer appears in New email → Linked task or subtask.
