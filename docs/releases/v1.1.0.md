# v1.1.0 — Rows marked done when their tasks are done

**Optional database migration schema v28, and one more Google scope to write to Sheets.**

A tracker can now tick a row (or set its status) by itself when the tasks and subtasks linked to it are completed, and write that to the connected Google Sheet.

- Edit a **Checkbox** or **Choice** column and tick **When the linked tasks are done**. For a Choice column, pick the option for done and the one to go back to if a task is reopened.
- A row counts as done when **every** linked task is completed. Reopening one undoes the mark, unless someone changed the value by hand.
- If the column comes from the connected Sheet, the same cell in the Sheet is updated. A cell someone changed in the Sheet since the last sync is not overwritten; the tracker shows a banner with **Write them now** or **Dismiss**.
- Writing to the Sheet uses the Google account that connected it, which needs to allow editing Google Sheets once (**Allow editing with my Google** in the tracker).

Before the deploy, add the `https://www.googleapis.com/auth/spreadsheets` scope to the OAuth consent screen of the Google Cloud project used for Gmail, and apply [schema v28](../../database/migrations/schema-v28-tracker-auto-done.sql).

After the deploy, confirm **v1.1.0**, hard refresh (Ctrl+Shift+R), and in a tracker that follows a Sheet: edit its done column, tick **When the linked tasks are done**, link two subtasks to a row, complete both, and check the row and the Sheet cell.
