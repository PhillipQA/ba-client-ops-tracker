# v0.6.60 — BRD Creator

Adds a dedicated BRD Creation workflow under Document Creation using the supplied iRipple BRD layout. It accepts incomplete source material, creates an editable best-effort business draft through the tenant Document Agent, supports the standard BRD sections and mapping table, exports to DOCX, and can hand reviewed structured BRD data directly to FSD Creation.

The release also adds BRD to the account document-template catalog. Existing databases require `database/migrations/schema-v17-brd-template.sql`; fresh database setup bundles migrations 1–17.

See `UPGRADE-v0.6.60.md` for installation and verification steps.
