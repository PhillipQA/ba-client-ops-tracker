# v0.6.80 — Sign Off Document

Released October 11, 2026.

- Rename the module to Sign Off Document.
- Add a Production Deployment Form / Sign Off Form toggle.
- Map the supplied Go Live Sign Off template.
- Make retained narrative sections editable.
- Start with two iRipple and two client signatory slots, with add/remove controls.
- Preserve each form's separate details, filename, signer emails, attachments and DocHub preparation when toggling.

Drafts are in memory and are not saved by leaving or refreshing the workspace. Additional signatories support up to 20 slots per side for document generation; DocHub preparation retains its limit of 12 active signers in total.

## Database action

Built-in Go Live generation needs no new template row. Apply [schema-v21-golive-template.sql](../../database/migrations/schema-v21-golive-template.sql) to enable optional custom Go Live template uploads/removal in Settings. Do not run the fresh setup script on an existing database.

See [Sign Off mapping and requirements](../setup/signoff-requirements.md) and the [upgrade guide](../setup/upgrade.md).

Recorded release validation: 39 focused Sign Off/integrations/DocHub checks, form-state checks, production build, server typecheck, database setup consistency and rendered Word review. The migration was included with the release; release notes do not confirm whether it has been applied to a particular deployed database.
