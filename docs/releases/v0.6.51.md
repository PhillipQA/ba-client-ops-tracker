# v0.6.51 — Centralized document templates

- Moves DRF, FSD, and Sign Off template management to **Settings → Templates**.
- Adds separate template cards with active status, upload/replace, remove, and built-in restore for FSD and Sign Off.
- Removes DRF template upload/removal controls from Document Creation. Document Creation now consumes the selected account template automatically.
- Keeps the current built-in FSD and Sign Off layouts as defaults until an Administrator replaces or removes them.
- Adds custom FSD DOCX support using the `{{FSD_BODY}}` marker plus optional document metadata markers.
- Adds schema v15 so one account can store DRF, FSD, and Sign Off template states independently while preserving the existing DRF template.

Existing databases must run `database/migrations/schema-v15-document-templates.sql` once before using v0.6.51.
