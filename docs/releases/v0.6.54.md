# v0.6.54 — FSD hard scope enforcement

## Fixed

- Advanced Mode FSD module checkboxes now act as hard exclusions instead of soft guidance.
- Unchecked software feature sections are removed from the AI output contract and cannot appear in the generated preview or Word document.
- Sources mapped specifically to an unchecked module are excluded from the FSD AI request.
- Mapping instructions for excluded module sections are ignored server-side.
- Preview and export table-of-contents behavior follows only the included sections.
- “5. Software Features” is attached to the first included software module when earlier module sections are excluded.

## Clarification

Shared or unmapped source documents are still sent to the Document Agent because they may contain requirements for selected modules. The AI is instructed to ignore content belonging only to unchecked modules. For strict source-level exclusion, map a source to the module it belongs to; if that module is unchecked, the source is not sent.

## Deployment

No database migration or dependency installation is required.
