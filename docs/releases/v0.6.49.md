# v0.6.49 — UI consolidation and DocHub history layouts

## Changes
- Removed **Create / Import RTM** from Document Creation. Requirements & Traceability remains available from the left navigation.
- Removed the duplicate **Appearance** section from Settings. Appearance remains under **My Themes**.
- Simplified My Themes to one workspace-wide background theme; per-client theme selection is no longer exposed or applied.
- Enhanced DocHub **Document history** with Row and Tile layouts.
- Added 3 / 5 / 10 items-per-page options, defaulting to 5, plus previous/next pagination.

## Database
No database migration is required for this release.
