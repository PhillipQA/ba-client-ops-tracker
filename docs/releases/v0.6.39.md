# v0.6.39 — Repository & README cleanup

This release reorganizes the source repository without intentionally changing user-facing application behavior.

## What changed

- Backend implementation moved under `server/`, grouped into accounts, AI, auth, documents, integrations, platform and shared services.
- The root `server.ts` remains as a small compatibility entry point for existing npm/Render commands.
- Supabase migration history moved from `supabase/` to `database/migrations/`.
- Upgrade notes moved from the repository root to `docs/releases/`.
- Password recovery and Sign-Off setup notes moved to `docs/setup/`.
- Added repository/server/database documentation explaining where code belongs.
- Replaced the long historical root README with a concise project overview and navigation guide.
- Expanded `.gitignore` so generated builds, local environments, patch backups, logs and TypeScript build-info files stay out of Git.
- Removed committed `tsconfig.app.tsbuildinfo`.
- GitHub Actions now uses `npm ci` for reproducible installs.
- Updated application version to `0.6.39`.

## Upgrade

Apply the v0.6.39 patch from a clean v0.6.38 working tree, then run:

```bash
npm run patch:status
npm run build
```

No npm dependency, Render environment variable or Supabase schema migration is introduced by this release.

## Important Git note

The patch physically moves source files. Commit the complete v0.6.39 result together so Git records the repository reorganization coherently. Do not cherry-pick only the deletion side or only the new folders.

Generated patch/full-build ZIP files should be attached to GitHub Releases rather than committed to the repository.
