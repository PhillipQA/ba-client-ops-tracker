# v0.6.53 — FSD image supporting documents

## Added

- FSD Creation accepts PNG, JPG/JPEG, WEBP, BMP, TIF and TIFF images up to 10 MB each.
- Uploaded images are OCR-read in the browser and automatically added as **Supporting document** sources.
- The FSD upload helper text now makes image/OCR support explicit.

## Unchanged

- Existing PDF, DOCX, TXT, MD, CSV and JSON source handling remains available.
- No database migration or dependency installation is required.
- Image OCR extracts readable English text; visual-only diagrams are not interpreted.
