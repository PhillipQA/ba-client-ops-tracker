# v1.0.1 — Clearer Google Sheet errors

**No database migration and no new setting.**

- A link to an **Excel file kept in Google Drive** now says it is an Excel file, names it, and says to open it in Google Drive and choose **File → Save as Google Sheets**, then use the new Sheet's link. Before, it said the Sheet could not be opened.
- If the **Google Sheets API or Google Drive API is turned off** in the Google Cloud project used for Gmail, the message says an admin needs to enable it.
- A Google Sheet that is not shared with you still says it cannot be opened.

After the deploy, confirm **v1.0.1**, hard refresh (Ctrl+Shift+R), and try **Trackers → From Google Sheet** with the Excel link again.
