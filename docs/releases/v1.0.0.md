# v1.0.0 — The code, reorganised

**No database migration and no new setting.** Deploy as usual (`npm ci && npm run build`). Every page looks and works as in v0.9.0.

What changed, for people working on the code:
- **Feature folders.** `src/features/<area>/` (action-center, trackers, email, work-hub, integrations, documents, requirements, tasks, notifications, reports, ai, settings, accounts, admin, clients, inbox), `src/app/` (shell, store, state hook, cloud sync), `src/shared/` (types, dates, version, HTTP helper, UI kit), `src/styles/` (global styles and fonts). Files were moved with `git mv`, so `git log --follow` keeps their history.
- **App.tsx** is the shell only: sign-in checks, the menu and which page shows. Its state is in `src/app/useAppState.tsx`; each screen is a page component that receives the app state.
- **server/index.ts** only wires middleware and routes, in the same order as before. `server/core/` holds config, environment loading, the database client, sessions and sign-in checks, and loading and saving each organisation's workspace. Route groups each have a `register…Routes(app)` module: auth, workspace store, internal admin, AI assistant, DRF documents, Discord, task comments, time and evidence. `.env` files now load before any other module.
- **Shared pieces.** `src/shared/ui` has the Dialog, Popover, Notice, SearchSelect/ClientSelect, Chips and the modal-dialog hook; `src/shared/http.ts` has `requestJson`, which every API helper uses.
- **Biome** formats and lints the code: `npm run format`, `npm run lint`, `npm run check`. 120 columns, single quotes, no semicolons. Rules that clash with existing patterns are off; accessibility and some style rules are warnings for now and are listed on every CI run.
- **CI** fails on Biome errors and posts the full test suite's totals as annotations. Four older tests that already failed in v0.9.0 still fail and still don't block the build.

One user-facing fix: when connecting a Google Sheet, an Excel file kept in Drive, or a Sheets API that is switched off in Google Cloud, now gets its own message instead of "cannot open that Sheet".

After the deploy, confirm **v1.0.0**, hard refresh (Ctrl+Shift+R), and open each page from the menu.
