# v0.6.98 — Trackers: clients, task and subtask cells, calculations

There is **no new database migration and no new Google permission**. Subtask cells use the task links table from [schema v25](../../database/migrations/schema-v25-tracker-task-links.sql) (added in v0.6.96); apply it if you have not.

- **Several clients per tracker**, chosen when creating or importing, or in Tracker details.
- **First column = the row's task**: **+ Task** picks an open task or creates one (you choose the client when the tracker has several).
- **Other cells = subtasks of that task**: **+** picks an open subtask or creates one named after the column (DRF, Go-Live…). Closed work is never offered; a closed subtask stays in its cell marked Done.
- **Create tasks** for selected rows, with a preview and confirmation.
- **Calculated columns** (`[Qty] * [Price]`, with + - * / and brackets) and a **SUM totals row** that follows search and filters.

After the deploy, confirm **v0.6.98**, hard refresh (Ctrl+Shift+R), and try **+ Task** and **+** on a tracker row.
