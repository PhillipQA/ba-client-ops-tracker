# BA Client Ops Tracker v0.6.58 — FSD preview guidance

Upload-time AI source review from v0.6.57 continues before document details are filled in. The preview button now stays unavailable until its prerequisites are complete, with the exact missing fields displayed beside it. Upload success and preview readiness have separate messages. The FSD screen shows the running app version for deployment troubleshooting.

This release uses the existing Document Agent and adds no new dependency or database migration. The user must still review OCR text and original visual documents.
