# v0.6.87 — Save Gmail attachments to Google Drive task folders

This release lets your team file Gmail attachments into a shared Google Drive, organized by client, project, task and subtask. See the [changelog](../../CHANGELOG.md) for details.

**Apply [schema v23](../../database/migrations/schema-v23-drive-attachments.sql) first.** It works on Supabase and on plain PostgreSQL (Northflank). On PostgreSQL, run it as the owner of the tables, or grant the app's database user access to `tenant_drive_accounts` afterwards.

1. **Google Cloud:** in the project that holds the Gmail OAuth client, enable the **Google Drive API**. The redirect URI stays the same.
2. **Settings → Integrations → Google Drive — team folder:** an account administrator clicks **Connect Google Drive** and signs in with the Google account that should own the team folder.
3. **Share** the new *BA Client Ops Tracker* folder with your team in Google Drive, or move it into a shared drive.
4. **Work Hub:** create a task from an email, then click **Save to Drive** next to an attachment and pick the task or subtask.

The file goes to `BA Client Ops Tracker / Client / Project / Task / Subtask` and appears on the task under **Saved to Google Drive**. The app keeps no copy of the file.

After the deploy, open the public app URL and confirm the current version, **v0.6.87**. A browser with the old version open may need one hard refresh (Ctrl+Shift+R).
