# v1.0.3 — A simpler review of new rows

**No database migration and no new setting.**

Turning new tracker rows into tasks and subtasks used to mean ticking rows, then picking one of four controls (new tasks, an existing task, a new task in the list, or plain rows), with the client and project settings below the list. The review is now one grouped list.

- **Grouped list:** each task with its subtasks indented under it, the way the Sheet groups them. Subtasks of a task from an earlier sync appear under that task's name.
- **One menu per row:** Task, Subtask of the task above, Subtask of another task…, Keep as a row, Decide later. The checkbox on a task includes or skips the task and its subtasks together.
- **Settings at the top:** Client, Project (choose **+ New project…** to name one), Task name from, Subtask name from.
- **Uploads** (CSV/Excel) are grouped the same way as a Sheet: a name in the first column starts a task; blank rows below it are its subtasks.
- **More options** keeps the rule-based bulk change and the per-column subtasks.

After the deploy, confirm **v1.0.3**, hard refresh (Ctrl+Shift+R), and open a tracker with rows waiting for review (or import a file).
