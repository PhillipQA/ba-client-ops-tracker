# v0.6.43 — DocHub document details fix

Fixes Document Creation → Document history → Details.

- The details dialog opens over the full page, including when a background theme is selected. The history panel no longer clips it.
- Long signatory lists and activity histories scroll inside the dialog. Its heading and close button stay visible, and the layout fits smaller screens.
- Escape, the close button, and clicking outside the dialog close it. Keyboard navigation stays out of the background controls, and focus returns to the Details button.
- Guidance follows the current signing status. Partially signed documents show that remaining signatures are pending; they no longer ask you to prepare signature fields again.
- Existing saved setup notes are hidden once obsolete. A successful status refresh also removes the outdated note from the stored document.

The dialog uses the selected Dark, Light, Gray, or original theme appearance. Document templates, background assets, RTM/AI import, signature counts, task assignment and completion behavior are preserved. This fix does not send signing invitations.

## Apply to v0.6.42

1. Stop the local app and keep your usual project/database backup. Confirm `npm run patch:status` reports **0.6.42**.
2. Save **ba-client-ops-patch-v0.6.43-dochub-details.zip** in `E:\Playwright`. From `E:\Playwright\ba-client-ops-tracker`, run:

```powershell
npm run patch -- "E:\Playwright\ba-client-ops-patch-v0.6.43-dochub-details.zip"
npm run build
npm run patch:status
```

3. Restart the local app, or commit and push the updated source through your existing Render deployment process. Refresh the browser after the updated app is running.
4. Open Document Creation → Document history → Details. Expand Signatories and activity to view the full list. Use Refresh status to retrieve the latest signing state.

Use the **patch ZIP** with `npm run patch`; it includes `patch-manifest.json`. The **full-build ZIP** is complete source for a clean checkout and is not a patch. For a clean checkout, keep your existing environment configuration, run `npm ci`, then `npm run build` and start the app as usual.

No new dependencies, environment variables or database migrations are required when upgrading from v0.6.42. The update preserves existing documents, signatories and activity history.
