# v0.6.82 — Task board, effort tracking and fixes

This release bundles the changes merged since v0.6.81. See the [changelog](../../CHANGELOG.md) for the full list.

- **Task board.** The Tasks page can switch between Table and Board, grouped by status or by who the task is waiting on, with drag-and-drop to move cards.
- **Effort tracking.** Optional hour estimates on tasks and subtasks, time logging with categories, and a new Effort panel in Reports with CSV export.
- **Linked-task schedule.** Creating a task from Work Hub → GitHub/GitLab → Linked work now sets Waiting on and optional start, due and follow-up dates.
- **Security hardening.** Current password required to change email or password, server-side session expiry, broader sign-in rate limits, security headers, and tighter access to other users' contact details.
- **Blank page after deploy fixed.** `index.html` is no longer cached, missing assets return 404, and an open tab reloads itself once after a deploy. Browsers stuck on the old version need one hard refresh (Ctrl+Shift+R).

No database migration is needed.
