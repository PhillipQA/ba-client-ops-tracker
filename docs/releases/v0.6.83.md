# v0.6.83 — More Sign Off forms and configurable Waiting on

This release bundles the changes merged since v0.6.82. See the [changelog](../../CHANGELOG.md) for the full list.

- **More Sign Off forms.** Document Creation → Sign Off Document now offers five forms: Production Deployment, Go Live Sign Off, **UAT Sign Off**, **UAT Deployment Approval** and **Training Sign Off**. The new Word templates match the look of the existing two. Details, section wording and table rows are editable, and each form has its own template card in Settings → Templates.
- **Configurable Waiting on options.** Internal Admin → Platform settings → Task configuration lets you add, rename, reorder and remove the Waiting on options per account. Accounts that never change the list keep the previous six options.

One optional database migration: apply [schema-v22](../../database/migrations/schema-v22-signoff-form-templates.sql) before uploading or removing custom templates for the three new Sign Off forms. Built-in generation works without it. Run it as the table owner (for Northflank, the admin user).
