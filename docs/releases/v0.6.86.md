# v0.6.86 — Download Gmail attachments from Work Hub

This release lets you download Gmail attachments from Work Hub. See the [changelog](../../CHANGELOG.md) for details.

- **Click to download.** Attachment names on Gmail messages in Work Hub are links. Each file is fetched from Gmail when you click it.
- **Nothing stored.** Files pass through the server to your browser only. The database keeps the file name, type and size, as it already kept the name.
- **Private.** Only the mailbox owner can download, and files always download rather than open inside the app.
- **Older messages** download the same way.

No database migration is needed. Gmail keeps its read-only permission, so users do not need to reconnect.

After the deploy, open the public app URL and confirm the current version, **v0.6.86**. A browser with the old version open may need one hard refresh (Ctrl+Shift+R).
