# BA Client Ops Tracker v0.6.57 — FSD source review

FSD sources are now interpreted as soon as they are uploaded or added as pasted text. Each review reports readability, supported facts/requirements with verified source excerpts, and clarification questions. This runs before required document details or writing presets are completed.

Generation reuses reviews of unchanged sources and combines their facts with the latest preset, guidance and checked scope. Original source text is retained for correction and evidence validation. Source or scope changes require reanalysis. Unreadable or incomplete sources cannot silently enter generation, and removing/resetting sources prevents their content from being reused.

Uses the existing per-account Document Agent and adds no dependencies or database migration over v0.6.56. English OCR remains the extraction path for images; visual relationships are not interpreted by this release.

For installation, costs/limits, migration prerequisites for older versions, and rollback, see [UPGRADE-v0.6.57.md](../../UPGRADE-v0.6.57.md).
