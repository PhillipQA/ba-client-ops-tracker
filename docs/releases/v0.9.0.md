# v0.9.0 — Trackers that follow a Google Sheet, and reviewing new rows

**Database migration:** apply [`database/migrations/schema-v27-tracker-sheets.sql`](../../database/migrations/schema-v27-tracker-sheets.sql) once.

**Google Cloud (the project used for Gmail in Work Hub):**
1. APIs & Services → Library → enable **Google Sheets API** and **Google Drive API**.
2. OAuth consent screen → Data access → add `https://www.googleapis.com/auth/spreadsheets.readonly` and `https://www.googleapis.com/auth/drive.metadata.readonly`.
3. With an **Internal** consent screen (Google Workspace) nothing else is needed. With **External**, these scopes need Google's review, or only listed test users can use them.

What's new:
- **From Google Sheet** in Trackers: pick a Sheet (yours, shared with you, or on a shared drive) or paste a link, choose the tab, the columns and the key column.
- **Sync now** and automatic sync every few minutes, one way (Sheet → tracker). Removed rows are kept and crossed out. Sheet columns are read-only in the tracker; your own columns are not.
- Built ready for **two-way** later: each row keeps its key and its values from the last sync.
- **Review** for new and imported rows: tick by hand or by a rule, then make them new tasks (in an existing or new project, with a subtask per chosen column), subtasks of an existing task, subtasks of a new task in the same list, or plain rows. A summary shows first.

After the deploy, confirm **v0.9.0**, hard refresh (Ctrl+Shift+R), then try Import a sheet and From Google Sheet.
