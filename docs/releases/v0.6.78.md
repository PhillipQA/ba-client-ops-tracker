# v0.6.78 — Work Hub login and manual sync

Merged October 9, 2026. This change supersedes the timed Work Hub sync behavior described in v0.6.76 and v0.6.77.

- Connected integrations sync once at sign-in, using their saved labels/repositories.
- Restoring the same login does not repeat the initial sync.
- Refresh now in Work Hub syncs all connected integrations. The top-bar Refresh now also reloads the workspace.
- Sync Gmail, Sync Discord, Sync GitHub and Sync GitLab refresh only their own source.
- No timer, browser focus event or automatic continuation starts Work Hub sync. Additional import pages require an explicit Sync.
- Saved pages are cached per signed-in user. Pagination, filters and edits can read/write saved data as needed.
- Discord's workspace bot still captures linked mentions and DMs to the bot; Sync Discord loads that saved inbox.

The sync change adds no database migration. Use the [current upgrade guide](../setup/upgrade.md) to update from source.

Verification commands:

```bash
npm run test:work-hub-sync
npm run test:egress
```
